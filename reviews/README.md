# Revisiones de contenido de Camasa

Esta carpeta registra el estado de revisión de las lecciones. `machine_checked` significa que se comprobó la estructura, el número de ejercicios y la presencia de respuestas y explicaciones; **no equivale a una aprobación lingüística**.

Antes de publicar una lección se requieren dos revisiones con `content-review-template.json`:

1. una revisión lingüística realizada por una persona competente o por una IA especializada, con las fuentes citadas;
2. una revisión pedagógica que valore objetivo, secuencia, variedad, carga cognitiva y evaluación del dominio.

La publicación solo procede cuando ambas decisiones son `approve`. Si alguna pide cambios, se crea una nueva versión del contenido y se repite la revisión afectada.
